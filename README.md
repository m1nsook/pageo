# Pageo

**Beautiful docs, built your way.**

Pageo is an open-source, local-first desktop documentation studio. Create and edit documentation visually, then export a static website that you can host anywhere.

> **Project status:** Early development. Pageo is not yet available on npm or as a desktop release.

## Vision

- **Visual-first editing:** A built-in desktop editor, without a separate CMS.
- **Local-first projects:** No account or cloud service required.
- **Portable project files:** Back up, move, and reopen your work.
- **Static publishing:** Export HTML, CSS, JavaScript, and assets for hosting anywhere.
- **Developer-friendly:** An npm package and CLI are planned alongside desktop releases.
- **Open source:** The editing and publishing tools will be open source.

## Planned technology

- Tauri 2 desktop application
- React + TypeScript
- Vite
- shadcn/ui + Tailwind CSS 4
- Bun for development and package management
