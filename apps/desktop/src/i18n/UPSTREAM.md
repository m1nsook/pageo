# Paglora translations

Reviewed locale snapshots sourced from [m1nsook/paglora-lang](https://github.com/m1nsook/paglora-lang), synchronized from commit `cb10d620a1390c7ffd0b1e7cee2ef0f0043b5d0a`. Make translations in that repository and sync from a local checkout using `node scripts/sync-translations.mjs ../paglora-lang`. English fallback is built in; Studio and website language are independent.
