# Paglora translations

Reviewed locale snapshots sourced from [m1nsook/paglora-lang](https://github.com/m1nsook/paglora-lang), synchronized from commit `c43640983d685eef02080b1de94c2469d6b6fb82`. Make translations in that repository and sync from a local checkout using `node scripts/sync-translations.mjs ../paglora-lang`. English fallback is built in; Studio and website language are independent.
