# Paglora translations

Reviewed locale snapshots sourced from [m1nsook/paglora-lang](https://github.com/m1nsook/paglora-lang), synchronized from commit `f534751391f0cc6296cd1e1f0f994ec28b7e3980`. Make translations in that repository and sync from a local checkout using `node scripts/sync-translations.mjs ../paglora-lang`. English fallback is built in; Studio and website language are independent.
