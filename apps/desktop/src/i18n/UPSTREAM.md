# Paglora translations

Reviewed locale snapshots sourced from [m1nsook/paglora-lang](https://github.com/m1nsook/paglora-lang), synchronized from commit `1d024c1686be39009b8f6c6389bd530b5ff15d53`. Make translations in that repository and sync from a local checkout using `node scripts/sync-translations.mjs ../paglora-lang`. English fallback is built in; Studio and website language are independent.
