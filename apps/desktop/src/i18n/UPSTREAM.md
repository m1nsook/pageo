# Paglora translations

Reviewed locale snapshots sourced from [m1nsook/paglora-lang](https://github.com/m1nsook/paglora-lang), synchronized from commit `4c41b11dd1e68ea3b72e84e04c795b760a2b4c05`. Make translations in that repository and sync from a local checkout using `node scripts/sync-translations.mjs ../paglora-lang`. English fallback is built in; Studio and website language are independent.
