# Security Policy

## Supported versions

Paglora is in early development and has no supported stable releases yet.

## Reporting a vulnerability

Please **do not** open a public issue for security vulnerabilities.

Use GitHub's **Report a vulnerability** feature in the repository's **Security and quality** section. The maintainers will review the report privately.

If private vulnerability reporting is not enabled yet, open a general issue requesting a secure contact method **without publishing vulnerability details**.
